# 第三、四章实例与算法 A 的补充检查

这两个脚本核对论文中的指定有限实例。它们保留参数恢复、测试效应比较、谱隙计算及完整相位等式的断言，使用 Python 标准库即可运行。所有参数都在脚本中列明，无须读取论文源码或联网下载数据；运行目录不影响计算。

## 运行方法

使用 Python 3.11 或更新版本。下面的脚本路径可替换为实际下载位置，输出路径由使用者指定。`ch34` 的输出目录以及算法 A 的输出文件须尚不存在，避免覆盖已有结果。请勿使用 `-O`；脚本会拒绝跳过断言的运行方式。

```bash
python3 -I -S -B /path/to/multihypergraph-thesis-checks/checks/ch34/replay_ch34.py --output-dir /path/to/results/ch34
python3 -I -S -B /path/to/multihypergraph-thesis-checks/checks/algorithm_a/algorithm_a_weights_check.py --output /path/to/results/algorithm_a.json
```

第一个命令生成 `ch34_checks.json` 和 `run_manifest.json`。前者包含计算结果，后者记录解释器、平台、脚本与结果的 SHA-256。第二个命令生成指定的 JSON 文件，其中包含参数、两组插值权、枚举行数和脚本 SHA-256。两个命令均向标准输出打印一行 JSON 摘要；断言未通过时以非零退出码终止。

## 第三、四章：参数恢复、测试效应与副本数

入口为 `checks/ch34/replay_ch34.py`。下表中的标签对应论文公式或附录标题，便于在编号调整后继续定位。

| 检查对象 | 固定参数与范围 | 论文标签 |
| --- | --- | --- |
| 一元参数恢复 | `q=3,n=1`，恢复 `2x+2x²`，回代全部 3 个输入 | `eq:ch03-q3-one-variable` |
| 二元参数恢复 | `q=3,n=2`，仅在 `(1,0)` 处为 1 的函数，回代全部 9 个输入 | `app:w1-ordinary-hypergraph-constraints` |
| 多重图实例 | `q=3,n=3`，恢复 `x₀x₁+2x₀x₁²+2x₀²x₁²+x₀x₂`，回代全部 27 个输入 | `eq:ch03-fig32-mg-polynomial` |
| 多重超图实例 | `q=3,n=3`，恢复 `x₀x₁²+2x₀x₁²x₂+2x₀²x₁x₂²+2x₂²`，回代全部 27 个输入 | `eq:ch03-fig32-mhg-polynomial` |
| 普通超图子类的接受效应 | `q=3,n=3,F=x₀x₁`，测试块 `{0,2}`、`{1}`；逐项比较条件相位、Fourier 标签接受规则和稳定子平均的指数 | `eq:ch04-ordinary-cover-reduction` |
| 谱隙和副本数 | 两块权重 `p=1/10,1/4,1/2`，以及三个等权单顶点测试；`ε=1/100,δ=1/20` | `tab:ch04-weight-samples`、`eq:ch04-exact-sample` |

参数恢复按支撑集大小逐层求解，并与给定的非零系数逐项比较，共回代 66 个输入。接受效应部分检查两个 `27×27` 矩阵，共 1,458 个矩阵位置；补集标签不同的位置在三种表达中均为零，其余位置比较模 3 指数，并使用共同的归一化分母。谱计算枚举每种策略的全部 27 个扇区，输出本征值重数和谱隙。

四行副本数依次为 `2995、1197、598、898`。对每行同时验证 `(1−εν)^N≤δ` 与 `(1−εν)^(N−1)>δ`，通过整数幂比较确认取整。简化充分界依次为 `2996、1199、600、899`。

模运算、参数回代、指数比较、本征值和上述整数幂比较使用整数或 `Fraction`，没有浮点误差。简化充分界涉及 `ln(20)`，采用 80 位精度的 `Decimal` 计算后向上取整；这部分是高精度数值复算，没有提供超越函数的严格区间证书。脚本中的谱公式取自论文的解析推导，本检查不重新证明其对任意目标态的成立条件。

## 第六章：算法 A 的两组插值权与操作次序

入口为 `checks/algorithm_a/algorithm_a_weights_check.py`，对应 `eq:qss6-compilation-weights`、`eq:qss6-local-compiled-operator` 及 `eq:qss6-designedphase`。脚本使用两个固定例子：

| 参数 | 第一个例子 | 第二个例子 |
| --- | --- | --- |
| `(q,k,m)` | `(5,2,2)` | `(7,3,1)` |
| 公开求值点 | `0,1,3` | `0,1,2,4,6` |
| 掩码位移 | `2,3` | `3,5` |
| 高次基函数 | `c₀³,c₀c₁²` | `c₀³,c₀⁴` |
| 低次余项 | `c₀+2c₁+4c₀²+2c₀c₁+3c₁²` | `2c₀+6c₀²` |
| 全部系数组合数 | `5⁴=625` | `7³=343` |

脚本中的索引从 0 开始，插值集合 `H` 取前 `k` 个求值点。第一组权重 `nu` 提取次数不超过 `k−1` 的多项式的最高次系数，第二组权重 `lambda` 提取次数不超过 `2k−2` 的乘积多项式的最高次系数。两个例子都明确检查两组权重不同。

对全部 968 组掩码与秘密系数，脚本依次检查负物理位移、位移后的求值标签、低次逻辑相位和完整编码相位等式。相位门使用更新后的标签，对应 `U_i=D_i(Q)S_i(t)` 从右向左执行的次序。计算全部采用有限域整数模运算，不包含浮点求解。

这些枚举核对算法 A 在所列参数下的完整相位关系。它们没有枚举任意参数，也不承担第六章隐私、恢复、固定编码门库判定或全部定理的证明。
