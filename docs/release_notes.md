# 0.1.0 发布说明

发布日期：2026-11-24。代码仓库为 [https://github.com/ZXD1001/multihypergraph-thesis-checks](https://github.com/ZXD1001/multihypergraph-thesis-checks)，版本页面为 [v0.1.0](https://github.com/ZXD1001/multihypergraph-thesis-checks/releases/tag/v0.1.0)。本版本采用 MIT 许可，未分配 DOI。

## 版本内容

1. 独立整理第三至第六章的 10 项有限检查，补齐统一入口、固定依赖、章节映射和软件引用信息。
2. 逐项复跑并与归档数学结果比较；整数和有限域计算精确核对，浮点比较的容差在运行入口中明确规定。
3. 提供版本 ZIP 和 SHA-256 校验值。代码目录中的 `SHA256SUMS.json` 可用 `python verify_integrity.py` 检查。

数学输入直接在各脚本中定义，`inputs/checks.json` 负责入口和结果文件索引。D10、D11、D12、D23、D27 等原输出字符串保留为计算标识，不代表当前论文中的公式编号。

## 计算范围

本版本核对指定有限实例，包括四个固定编码的 62,500 个位移—目标组合，其中 2,500 个可行、60,000 个排除。保存的 75 份负证书针对三个指定目标；一般结论的证明仍见论文。六方完整视图检查采用模块分解、偏迹和秩论证，没有构建全部 `5^10` 维密度矩阵。

公开文件包含计算脚本、基线结果及运行说明，不包含论文全文、评阅意见、签字扫描页、历史修改工具或个人路径。此次代码发布不修改论文及历史回复材料。

## 后续维护

修改数学输入时，应保留旧版本、核对变化原因，并为新结果单独建立版本。不要为使比较通过而直接用新输出覆盖归档基线。更新源码或发布元数据后，需重新生成校验清单及 ZIP。

使用 Git 客户端时，可据 `gitignore.template` 建立忽略规则，避免将 `results/` 或虚拟环境纳入仓库。论文中的软件链接及可选永久存档由作者后续另行安排；公开日期与历史论文修订日期分别记录。
